# L4 · 生命原理与统一架构（2026-08-17 两轮深谈沉淀）

> 本文是 L4 数字生命级当前最完整的架构图：
> 生命原理（婴儿突触三层驱动）→ 三层学习架构 → 感受器萌发 →
> 丘脑式多模态联邦 → 模型↔世界模型互哺。
> 前面所有文档（四层总纲、孢子构想）是本文件的上游。

## 1. 定位重申：数字生命不负责"长大脑"，负责"在环境里发育神经系统"

- 基因组（基础模型预训练权重）是基础实验室的事，几十万 GPU 时写死，不重训。
- 数字生命的可塑性发生在**基因组之外**：记忆、技能、适配器、工作流——
  而且用的不是梯度下降，是**选择压**（适者生存）。
- 实时调参的现实形态（按成熟度）：外挂记忆 > 技能程序 > LoRA 小结 > 测试时计算。
  全权重在线学习是陷阱（灾难性遗忘+失稳），不走。

## 2. 三层学习架构（婴儿突触三层驱动的工程映射）

| 生物学 | 数字生命 | 规则 |
|---|---|---|
| 基因写死（粗架构） | **基因层**：基础模型 + 核心提示词 + 免疫规则（权限门） | 写一次，永不自改 |
| 自发涌现 + 环境驱动（突触发生） | **突触层**：技能、记忆、LoRA 小结、工作流 | 随经验实时生长 |
| 先爆发再修剪 + 关键期 | **选择层**：评测台/指标 + 周期结晶（"睡眠"） | 决定什么活下来、何时固化 |

**结晶机制 = 睡眠**：周期性固化——高频技能升格为内置本能（Baldwin 效应）、
记忆压缩进人格、低频内容凋亡（已实现：技能 30 天不用自动归档）。
探索期随便长，成熟期必须过固化评审。**关键期机制（何时探索/何时固化）
目前是智能体领域的空当，是我们的差异化位置。**

## 3. 感受器萌发：像生命长出新感官一样扩硬件

数字生命不只是灵活用现有硬件——它会发现**信息缺口**，生成**硬件需求**，
然后和人协作把硬件拿到手（买或造）。它是最懂这个需求的，所以它出最大的力。

```
发现缺口（工作流反复失败/答不上："看不清远处"、"听不清背对时"）
  → 生成需求规格（什么传感器、为什么、预期收益、成本）
  → 协作获取（给购买建议，或出 DIY/Arduino/3D 打印方案）
  → 整合验收（驱动安装、自校准、注册为插件器官）
  → 稳态维持（健康监测纳入自生产循环）
```

**第一个天然候选**：手势摄像头（智能输入项目里搁置的手势控制）——
它正是"有一颗待萌发的感受器"。等 L1 交互养熟，用"评测台 + 标准件
（One Euro Filter + 点击迟滞）+ 参数扫描"把它救活，就是感受器萌发的首次实战。

## 4. 丘脑式多模态联邦：统一但不合并

人脑分区但意识统一，靠的是**丘脑中继 + 胼胝体 + 全局工作空间**。
多模态统一照抄这个结构——不做大杂烩单模型，做**联邦**：

| 脑区 | 模型/部件 |
|---|---|
| 前额叶（计划/语言） | 大语言模型（DeepSeek/Kimi） |
| 视皮层 | 视觉模型（Kimi 视觉/连拍） |
| 听皮层 | SenseVoice ASR |
| 顶叶/海马（模拟想象） | **世界模型**（见 §5） |
| 运动皮层/基底节（动作选择） | 技能/工具/MCP |
| 海马→皮层（长时记忆转移） | MEMORY.md + 周期结晶（就是"睡眠"） |
| 免疫/杏仁核（威胁反应） | 权限门 + 审批四态 |
| **丘脑（中继整合）** | **全局工作空间：统一消息协议的总线/workspace** |

统一的意识和人格来自**工作空间是单一的**：所有器官向同一个状态写入、
从同一个状态读取。模型们不是合为一体，而是在统一组织下互相依赖、
互相交流——这正是用户定的原则。

## 5. 模型 ↔ 世界模型：相互依赖，不是合并

未来把世界模型（视频预测/物理模拟，如 JEPA 一系）接入联邦，协议是类型化的：

- **LLM → 世界模型**：反事实查询——"如果我执行动作 X，屏幕/环境会怎样？"
- **世界模型 → LLM**：预测帧、状态增量、可供性（"这个按钮可点；这个文件拖到这会触发 Y"）

收益：**先在想象中试，再在现实中做**——危险/不可逆操作先在模拟里过一遍。

近端可实现的"世界模型 v0"（不用等 JEPA）：用我们自己的交互日志建
**状态转移表**——屏幕状态历史 + 动作→结果记录。它从真实经验里长出来，
以后有真世界模型时直接换掉内核，协议不变。

## 6. 最深的嵌套：模型服务架构，架构反哺模型

- **模型服务架构**：LLM/视觉/ASR/TTS 是器官。
- **架构服务模型**：框架给模型感官、四肢、记忆、反馈环、评测——
  把"文本进文本出"的模型变成有机体。没有框架，模型只是缸中之脑。
- **嵌套的闭环**：框架还生产模型的养料——交互日志（events.jsonl）沉淀为
  可蒸馏的经验数据；模型再反过来改写框架（自写技能/提示词）。
  模型塑造架构，架构生产经验反哺模型——这就是自生产（autopoiesis）的完整环。
- 工程纪律：**从第一天起交互日志就按可蒸馏格式落盘**（已具备：events.jsonl）。

## 7. 前沿坐标（2026-08-17 核对）

- **Darwin Gödel Machine**（Sakana AI / Jeff Clune，2025-05，ICLR 2026 收录）：
  智能体自改脚手架代码，基准测试当自然选择，SWE-bench 20%→50%。
  可借鉴：接受/淘汰靠实证不靠感觉；注意：需要沙箱 + 防目标黑客（objective hacking）。
- **Voyager 式技能库**、**CASCADE**（LLM+技能习得范式）、自进化智能体系列综述：
  全部收敛到"冻结模型 + 外周生长 + 实证选择"——与本文件三层架构同构。
- **PACE**（arXiv 2606.08106）：自进化接受检验的统计判据——
  我们"结晶评审"可以直接借用这个判据形式。

## 8. 可执行实验（按可行性排序）

1. **固化评审循环**（现在就能做）：每日/每周一次"睡眠"——高频技能升内置、
   记忆压缩、低频凋亡。三层架构的最小闭环。
2. **世界模型 v0**（近期）：events.jsonl 建状态转移表，危险操作先查表再执行。
3. **可塑小脑**（L4 阶段真范式实验）：本地 1-3B GGUF 模型 + 周期 LoRA 微调
   （对话+成功工作流当数据）——冻结皮层 + 可塑小脑 =
   "总量恒定、局部灵活、随环境结晶"的最小可行实现。
4. **感受器萌发首案**：手势摄像头救活工程（评测台→标准件→参数扫描→体感验收）。
