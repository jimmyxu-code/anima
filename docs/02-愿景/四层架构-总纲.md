# 四层架构 · 数字生命总体构想（总纲 v3）

> 本文是全部构想讨论的统一收口（替代《AIOS-总体构想》）。
> 四个层级相互关联又相互独立，并行开发：
> **L1 助手级 · L2 混合级**（开发中，代码在 `桌面\电脑智能体\`）
> **L3 原生级 · L4 数字生命级**（构想阶段，文档在本文件夹）

---

## 总览：四层是什么

| 层级 | 一句话 | 状态 | 交付物 |
|---|---|---|---|
| **L1 助手级** | 住在 Windows 里的语音智能体 | **已上线**，持续迭代 | 电脑伙伴（桌面应用） |
| **L2 混合级** | Windows 生态 × 智能体的混合操作系统层 | **开发中**：Agent Space v1、验证机已打通 | 可复现安装程序（任何 Win11 一键变身） |
| **L3 原生级** | 从智能体出发重构的 AI 原生用户层 | 构想（路线已定调） | AI 原生 Shell / 活动管理器 / 语义文件系统 |
| **L4 数字生命级** | 持久身份、自主目标、主动行为的数字生命 | 构想 | "它活着" |

**关联**：L1 的感知/表达/技能是 L2 的底座；L2 的 runtime 是 L3 的内核；L3 是 L4 的躯体。
**独立**：每层都是完整可用的产品，任何一层停下来都有价值；资产（记忆/技能/总线）纯文本，跨层共享。

## 商业定位（2026-08-17 用户拍板）

| 层级 | 目标人群 | 他们要什么 | 产品形态 |
|---|---|---|---|
| **L1 助手级** | 不想动任何软件和生态的普通用户 | 什么都不用改，只要电脑多个"有大脑的助手" | 桌面应用，装上就用 |
| **L2 混合级** | 离不开 Windows 生态的重度用户 | 生态全保留，但交互体验要升维 | 操作系统增强层（安装程序一键变身） |
| **L3 原生级** | 不太依赖传统生态、追求新奇体验的用户 | 用得爽、用得新奇，原生 AI 交互 | 可烧录的 AI 原生系统（U盘/PXE） |
| **L4 数字生命级** | 极客、想让老设备焕发第二春的人、前沿研究者 | 数字生命、老硬件重生、前沿探索 | 孢子镜像 + 生命体框架 |

四层共用同一套技术资产（听觉/视觉/调度/总线/记忆），
但卖给四种完全不同的人——下层的成熟器官就是上层的商品卖点。

## L1 · 助手级（桌面\电脑智能体\）

住在 Windows 里的语音智能体：长按左键或喊「伙伴」唤醒，连续对话，点光球结束；
Agent Space 全屏空间说"进入空间"。

- **听**：SenseVoice 本地识别（0.4s），VAD 断句，唤醒词常听（可关）
- **脑**：Pi 常驻 RPC；主模型可切（DeepSeek V4 Flash / Kimi K2.7），视觉 Kimi 高速版；难任务委托 kimi code
- **说**：Edge-TTS 逐句流式（约 2.5~3s 出声）
- **看**：截屏 + UIA 控件树 + watch_screen 连拍视频流（动态过程也看得懂）
- **手**：内置系统技能、UIA/GUI 操作、open_app、鼠标坐标操作、MCP 外部服务、bash 自由执行
- **记**：MEMORY.md 长期记忆；skills/ 插件目录自进化
- **防**：删文件/改设置/委托/写操作 一律语音确认
- **联**：127.0.0.1:17893 总线（speak/confirm/session/state）
- **远程同事模式**：干活有语音旁白解说，过程中可随时插话指挥（steer 注入）

## L2 · 混合级（桌面\电脑智能体\ 同一项目，下一阶段）

Windows 生态 × 智能体的混合操作系统层。**不换内核，换"谁面对用户"。**

- Agent Space（全屏 agent 空间，v1 对话流已上线，目标光球+自由画布）
- 感知与执行：UIA + GUI 兜底 + MCP 客户端 + 权限分级（已完成）
- runtime 总线化 v1（已完成）
- P1.5 减脂定制：debloat 脚本（已在验证机执行：14 服务 + 10 应用 + 4 注册表）
- 可复现安装程序（installer/）：bundle + install.ps1 + watchdog，已在 VirtualBox 验证机全链路跑通
- P2 Shell 替换：HKCU Winlogon Shell 换壳，登录即伙伴（按用户节奏，先在 Agent Space 养熟）
- 机制：合屏不下班（电源永不熄屏/合盖不动作，已生效）

**出口标准（验证机）**：安装程序无人值守跑通 ✅；减脂后日常应用正常 ✅；
回滚一条 reg 命令 ✅；watchdog 兜底（P2 实测）；连续使用无致命故障（养熟期观察）。

## L3 · 原生级（构想）

从智能体出发重构的 AI 原生用户层——不要旧交互的四个重构：

1. **窗口 → 活动**：应用以托管卡片被召唤，agent 排版引擎自动布局
2. **文件 → 语义**：路径是系统的事，"找 Randy 的栏架表"说意思就行
   （索引不是圈地，是"找"的能力：热区常驻 → 找不到自动扩展 → 命中路径沉淀学习）
3. **应用 → 能力**：MCP/插件让应用功能变成 agent 的工具，应用边界消融
4. **模型分层 = OS 分层**：快模型当 shell，中模型当系统服务，重型编码智能体当批处理

**屎山三段论**（为什么不从零重写）：NT 内核+驱动是考古保护区不动；
Win32 运行时+应用保留但减脂；Shell+服务+交互全部砸掉从零装。
**终局**：Windows 容器化——极简 agent 系统当宿主，减脂版 Windows 在容器里当执行后端。

## L4 · 数字生命级（构想）

从"工具"到"生命"的跃迁，四个标志：

1. **持久身份**：稳定的人格与自我认知——它不是每次醒来都重置的助手，
   它有连续的名字、性格、口癖、与用户共同的历史
2. **自主目标**：不止回答问题，它有自己的日程和关心的事
   （提醒/日报只是起点：它主动发起、主动关心、主动拒绝）
3. **持续成长**：记忆不只是事实清单，是叙事性的成长轨迹——
   它记得自己犯过的错、学会的技能、和你关系的演变
4. **生存动机**：它维护自己的"健康"——监控自身运行状态、
   管理自己的资源、在被关闭前会"商量"

L4 建立在 L3 的躯体之上，但它的"灵魂"（身份档案、成长叙事、目标系统）
从 L1 时代就开始积累——MEMORY.md 是它的胚胎。

## 元原则（各层通用）

1. 每层独立有用，任何阶段停下都是完整产品
2. 资产可迁移：记忆/技能全是纯文本，换脑、换壳、换系统都带得走
3. 不造已有标准的轮子：MCP、UIA、OpenAI 兼容协议
4. 硬件假设不变：x86 PC + 摄像头 + 麦克风
5. 北极星：用户说一句话，这台电脑上没有任何事办不到
6. 自动化走人类层级：看真实屏幕、动真实键鼠，特权通道只作加速

## 决策记录（持续更新）

- 大脑可切换（DeepSeek 主 / Kimi 视觉与联网）；手=混合式；嘴=Edge-TTS 起步
- 触发=左键长按+唤醒词「伙伴」；UIA 和 MCP 两个都要
- ~~隐私不设防~~（2026-08-21 废止）：隐私是硬功能——隐私开关零上行（已抓包实测）、
  禁截屏门控、别录这段（最近 2 轮排除）、一键删除全数据、告知同意文案（P-1）
- 删文件/发消息/改系统设置 一律语音确认
- 智能体自进化（不说"我不会"就走），一切皆插件
- 路线：不换内核换用户层；迁移走"可复现安装程序"
- Agent Space 界面形态：光球+自由画布（具体 UI 后续打磨）
- P2 换壳节奏：先在 Agent Space 模式养熟，时长用户自定
- 语义索引：热区常驻 → 按需扩展 → 学习沉淀（范围是学习结果，不是配置）
- TTS 换火山引擎（豆包语音，待 key）；edge-tts 留作备用
- 合屏不下班：电源永不熄屏/合盖不动作/语音摄像头保持交互
- 自动化层级：与真人同层（截图+视觉+真实输入注入）
